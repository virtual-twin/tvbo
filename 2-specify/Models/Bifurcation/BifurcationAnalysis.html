Bifurcation Analysis

2Specify·Bifurcation & continuation

Bifurcation analysis reveals how a system’s qualitative behavior changes as parameters vary: fixed points, oscillations, and the transitions between them.

TVBO supports multiple backends for bifurcation analysis using the same Continuation specification:

  • BifurcationKit.jl: Julia-based, via exp.run("bifurcationkit.jl")
  • PyRates/PyCoBi: Python-based (AUTO-07p), via exp.run("pyrates-bifurcation")

Generic2dOscillator

The Generic 2-Dimensional Oscillator (G2D) is a phenomenological, coupled, nonlinear two-dimensional (i.e., two state-variables (‘V’, ‘W’)) oscillatory, neural mass model. The G2D is a generalization of the well-known FitzHugh-Nagumo model (FitzHugh, 1961; Nagumo et. al, 1962), adapted here for reproducing a wilder class of dynamical configurations of physiological phenomena as observed in neuronal population using phase-portrait method.

autonomous: True; modes: 1; state variables: 2; parameters: 12.

State Equations

\[ \dot{V} = d \tau \left(I \gamma + V g + V c_{local} + W \alpha + c_{glob} \gamma + e V^{2} - f V^{3}\right) \] \[ \dot{W} = \frac{d \left(a + V b + c V^{2} - W \beta\right)}{\tau} \]

State Variables

Variable Equation Domain / Sampling Flags Description
\(V\) differential (order 1) [-2, 4] coupling, recorded V_G2D is the first state-variable of the Generic 2-Dimensional Oscillator model, that can be associated with membrane potentials and sodium activation (FitzHugh, 1961)
\(W\) differential (order 1) [-6, 6] recorded W_G2D is the second state-variable of the Generic 2-Dimensional Oscillator model, that can be associated with accommodation and refractoriness and considered to represent potassium activation, sodium inactivation, or both (FitzHugh, 1961)

Parameter Value Domain / Sampling Description
\(I\) 0 [-5, 5], step=0.01 Baseline shift of the cubic nullcline
\(a\) -2 [-5, 5], step=0.01 Vertical shift of the configurable nullcline
\(\alpha\) 1 [-5, 5], step=0.0001 Constant parameter to scale the rate of feedback from the slow variable to the fast variable.
\(b\) -10 [-20, 15], step=0.01 Linear slope of the configurable nullcline
\(\beta\) 1 [-5, 5], step=0.0001 Constant parameter to scale the rate of feedback from the slow variable to itself

Codim-2 Bifurcation Analysis

Codim-2 continuation traces how bifurcation points (folds, Hopfs) move in a two-parameter plane. This reveals cusp, Bogdanov-Takens (BT), and generalized Hopf (GH) organizing centers.

Choose parameter pairs that interact nonlinearly, such as I (nullcline shift) with b (nullcline slope), rather than two shift parameters like I and a which produce trivially parallel curves.

Both backends support codim-2. Add a continuation with free_parameters inside a branch:

cont_c2 = Continuation.from_string(
    """\
name: eq_I_with_codim2
dynamics: Generic2dOscillator

free_parameters:
    - name: I
      domain:
          lo: "-10"
          hi: "20"

branches:
    - name: po_from_hopf
      source_point: "hopf:all"
    - name: hopf_curve_in_b
      source_point: "hopf:all"
      bothside: true
      continuation:
          name: c2_hopf_in_b
          free_parameters:
              - name: b
                domain:
                    lo: "-20"
                    hi: "0"
          max_steps: 500
          ds: 0.01
"""
)

exp_c2 = SimulationExperiment(dynamics=model, continuations=[cont_c2])

Network (whole-brain) continuation

The examples above continue a single node. When the experiment carries a multi-node Network, exp.run("bifurcationkit.jl") continues the coupled system instead: the state is laid out as n_nodes blocks per state variable, each long-range coupling term becomes a connectivity matvec c = W · s evaluated once per step (with W taken from network.weights_matrix), and the per-node right-hand side runs in a loop. This is the vector field a whole-brain equilibrium diagram is continued along, such as the global-coupling G bifurcation of a Wong–Wang network.

No special flag is needed: attach a network and continue in the coupling parameter. The recorded observables become per-node summaries (<state>_max, <state>_mean across nodes), so the branch plots the maximum firing across the network against G, as in Deco et al. (2014) Fig. 2c.

from tvbo import Continuation, Dynamics, SimulationExperiment
from tvbo.classes.network import Network

model = Dynamics.from_ontology("ReducedWongWangExcInh")

cont = Continuation.from_string(
    """\
name: eq_G
dynamics: ReducedWongWangExcInh
free_parameters:
    - name: G
      domain: {lo: 0.0, hi: 6.0}
ds: 0.005
ds_max: 0.05
max_steps: 2500
detect_fold: true
detect_bifurcation: 2
initial_state: {method: time_integration, duration: 5000.0}
bothside: true
"""
)

exp = SimulationExperiment(dynamics=model, continuations=[cont])
exp.network = Network.from_matrix(weights, lengths)  # e.g. a 66-region connectome

bif = exp.run("bifurcationkit.jl")
bif.continuations["eq_G"].plot(VOI="S_e_max")  # max excitatory gating across nodes vs G

Heterogeneous parameters. A per-node parameter — for example the feedback-inhibition weights J_i fitted per region (FIC) — is supplied as a length-n_nodes array; it is emitted as a Julia vector and gathered per node inside the loop. Scalar parameters (such as the feed-forward-inhibition switch lambda) stay scalar. Special points are classified through the ontology’s bifurcation taxonomy (see ontology/tvb-o-bifurcation.ttl): a saddle-node fold is reported as a limit point (LP) even when the backend labels it a generic branch point, by testing whether the continuation parameter turns around at that point.
