Class: RegionMapping

Maps vertices to parent regions for hierarchical/aggregated coupling

URI: tvbo:class/RegionMapping

Slots

Name Cardinality and Range Description Inheritance
label 0..1
xsd:string		 direct
description 0..1
xsd:string		 direct
dataLocation 0..1
xsd:string		 Add the location of the data file containing the parcellation terminology direct
vertex_to_region *
xsd:integer		 Array mapping each vertex index to its parent region index direct
n_vertices 0..1
xsd:integer		 Total number of vertices direct
n_regions 0..1
xsd:integer		 Total number of regions direct
