# Jansen1995

Replication of the simulation experiments in Jansen & Rit (1995), *Electroencephalogram and visual evoked potential generation in a mathematical model of coupled cortical columns*. Six experiments cover the paper's Figures 3–6 and 8–11: the coupling-strength sweep that moves a single column through its alpha regime, the two-column runs with an inter-column delay, and the flash-evoked potentials. "Reproduce" here means the reported qualitative results, not a bit-exact rerun of the authors' own integrator.

This is a BIDS study dataset (`DatasetType: "study"`), and it is the layout's worked example inside this repository — `tvbo validate study .` passes on it. `Jansen1995.yaml` is the whole specification; `code/` holds the plotting callables it references by bare module name; `docs/figures/` is where the figures render.

**One deviation, deliberate.** The report is `Run_Jansen1995.qmd` at the study root rather than `docs/report.qmd`, because this study lives inside the tvbo documentation site, which owns the page and renders it from its own Quarto project. A standalone study puts its report in `docs/` and gets a `_quarto.yml` of its own; nesting a second Quarto project here would break the parent build.

Entries above that this study has no use for are simply absent: it declares no spec fragments, sources no external data, and runs locally rather than as a kit. The record describes what a study *may* hold, and `tvbo validate study` asks only for what it marks required.

## Reproduce

```bash
tvbo validate study .          # the tree and the filenames conform to the layout
quarto render Run_Jansen1995.qmd
```

Rendering executes the experiments and writes each figure into `docs/figures/`, which is why that directory is not tracked.

Nothing here is sourced rather than computed; `sourcedata/README.md` says so and why that is itself worth recording.
