PDE Simulation

TVBO supports surface-based partial differential equations using finite element methods via scikit-fem.

Diffusion on a Cortical Surface

A minimal diffusion equation on the cortical surface mesh:

\[\frac{\partial u}{\partial t} = \nabla \cdot (D \, \nabla u)\]

with Dirichlet boundary conditions (\(u = 0\) on boundary).

YAML Specification

label: "Cortical diffusion"
description: "Solve u_t = div(D * grad(u)) with zero Dirichlet boundary."
field_dynamics:
    domain:
        label: "Cortex"
        coordinate_space: {name: "MNI152"}
    field:
        label: "u"
        quantity_kind: "concentration"
        initial_value: 1.0
        mesh:
            element_type: triangle
            dataLocation: "path/to/cortex.pial.gii"
    operators:
        - operator_type: laplacian
          coefficient:
              name: "D"
              value: 1.0e-5
    boundary_conditions:
        - bc_type: Dirichlet
          value: {rhs: "0"}
    solver:
        discretization: FEM
        time_integrator: "implicit Euler"
        dt: 10
integration:
    duration: 2000

Running a PDE Experiment

from tvbo import SimulationExperiment

exp = SimulationExperiment.from_file("path/to/pde_experiment.yaml")
result = exp.run('pde')

# Visualize the solution on the mesh
ns = exp.execute('pde')
ns.visualize(result.data[-1])

Generated Code

The PDE backend generates a self-contained scikit-fem solver:

code = exp.render_code('pde')
print(code[:500])

The generated code includes:

  • _load_mesh() — loads GIFTI (.gii) or general meshio formats
  • build() — assembles mass and stiffness matrices
  • solve_pde() — implicit Euler timestepping
  • visualize() — matplotlib field plot
