# TVBO — Repository Guide for AI Agents

This file is the **cross-tool entry point** for AI coding assistants working in
this repository. Claude Code, GitHub Copilot, Cursor, Aider, Codex CLI, and any
other tool that follows the [agents.md](https://agents.md/) convention will
read this whole file.

## What is TVBO?

**TVBO (The Virtual Brain Ontology)** is a knowledge-representation and
simulation toolkit for large-scale brain network models — three pillars plus a
platform:

1. **LinkML datamodel** — `schema/*.yaml`, generated into Python types under
   `tvbo/datamodel/`.
2. **Ontology** — `ontology/*.{owl,ttl,shacl}`, loaded via `owlready2`.
3. **Python package** — specifies models, loads ontology-backed classes
   (`tvbo/classes/`), generates backend code (`tvbo/codegen/` +
   `tvbo/templates/` + `tvbo/adapters/`), and executes it (`tvbo/run/`).

The **platform** at [tvbo.charite.de](https://tvbo.charite.de) is an Odoo layer
that shares curated knowledge and experiments; a FastAPI surface (`tvbo/api/`)
mirrors it locally.

See the `overview` skill for the full picture — pillars, supported backends,
and installation.

## Working in this repo (maintainers)

- **Tests:** `pytest`. Backend tests carry markers (`backend_jax`,
  `backend_tvb`, `backend_julia`, …); slow tests are excluded by default
  (`--run-slow` to include). See the `tests-and-backends` skill.
- **Code generation:** Mako templates in `tvbo/templates/`, dispatched from
  `tvbo/codegen/`. See the `codegen-templates` skill.
- **LinkML schema:** edit `schema/*.yaml`; the regeneration pipeline produces
  `tvbo/datamodel/**`, which is excluded from `ruff` and `mypy`. **Never**
  hand-edit the generated dir. See the `linkml-schema` skill.
- **Git:** the user owns all version control — agents must never run
  `git add` / `git commit` / `git push`. See the `git` skill.

## Skills

This repo's skills live in **canonical form** under `skills/` (maintainer
skills) and `tvbo/skills/canonical/` (user skills shipped in the wheel).
Each skill is rendered into per-tool adapter formats by:

```bash
tvbo skills sync              # regenerate this file's index + .claude/skills/ + .github/instructions/
tvbo skills install --target claude-code   # user-side: drop user skills into ~/.claude/skills/
tvbo skills uninstall          # remove previously installed user skills
```
