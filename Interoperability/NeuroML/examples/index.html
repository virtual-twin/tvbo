NeuroML/LEMS Examples

Replicating all canonical NeuroML2 examples in TVBO with numerical validation

Overview

This section reproduces every canonical NeuroML2 LEMS example using TVBO. Each QMD notebook:

  1. Defines the model in TVBO (as a SimulationExperiment YAML spec)
  2. Renders to LEMS XML via exp.render("lems")
  3. Runs the original NeuroML2 example via jNeuroML
  4. Runs the TVBO version via NeuroMLAdapter.run()
  5. Compares time-series numerically (RMSE, correlation, max error)
  6. Plots overlaid reference vs TVBO traces

Prerequisites

pip install pyneuroml matplotlib scipy

jNeuroML (Java-based) is required for running the reference examples. It is bundled with pyNeuroML.

NML2 File Documentation

These pages document the structure of canonical NML2 example files, with TVBO representations showing the equivalent dynamics.

NML2: Abstract Cells Catalog of all abstract cell types — iafTau, iafRef, Izh, AdEx, FHN, PinskyRinzel

NML2: Full Cell Complete cell with morphology, channels, and biophysical properties
NML2: Full NeuroML Complete NeuroML document with cell, channels, network, and inputs
NML2: Gap Junctions Electrical synapse definitions and gap junction connections
NML2: Inputs All input types — pulse, sine, ramp, voltage clamp, spike generators
NML2: Instance-Based Network Network with explicit instance placement and coordinates
NML2: Simple Ion Channel Minimal HH-style ion channel definitions
NML2: Simple Morphology Cell morphology definitions with segments and segment groups
NML2: Single-Compartment HH Cell Full NeuroML cell element with morphology, biophysics, and channel populations
