Ex4: Kinetic Scheme Channels

Ion channels defined via kinetic scheme (Markov) state transitions

Model: Kinetic Scheme Ion Channels

This example demonstrates ionChannelKS — ion channels defined by Markov state transitions between open/closed states. The k_vh channel uses a vHalfTransition with rates:

\[r_{f0} = \frac{\exp(z\gamma(v - v_{Half})/k_{te})}{\tau}, \quad r_{r0} = \frac{\exp(-z(1-\gamma)(v - v_{Half})/k_{te})}{\tau}\]

\[r_f = \frac{1}{1/r_{f0} + \tau_{Min}}, \quad r_r = \frac{1}{1/r_{r0} + \tau_{Min}}\]

where \(k_{te} = 25.3\,\text{mV}\). This reduces to the standard ODE \(\frac{dn}{dt} = r_f(1-n) - r_r \cdot n\), which TVBO represents as derived variables.

The cell has a standard HH Na channel (\(m^3 h\)) and the KS K channel (\(n\), instances=1):

\[C\frac{dv}{dt} = -g_{Na}m^3 h(v - E_{Na}) - g_K n(v - E_K) + I_{\text{ext}}\]

1. Define in TVBO

from tvbo import SimulationExperiment

# Ex4 parameters: pointCellCondBased, C=1pF
# Na: 6000 channels × 20pS = 120 nS, erev=50mV (standard HH rates)
# K (k_vh): 1800 channels × 8pS = 14.4 nS, erev=-77mV (KS vHalfTransition)
# vHalf=0mV, z=1.5, gamma=0.75, tau=3.2ms, tauMin=0.3ms, kte=25.3mV
# z*gamma/kte = 1.125/25.3 ≈ 0.04447, z*(1-gamma)/kte = 0.375/25.3 ≈ 0.01482

exp = SimulationExperiment.from_string("""
label: "NeuroML Ex4: KS Channels"
dynamics:
  name: HH_KineticScheme
  parameters:
    C:     { value: 1.0,    description: "Membrane capacitance (pF)" }
    g_Na:  { value: 120.0,  description: "Total Na conductance (nS)" }
    g_K:   { value: 14.4,   description: "Total K conductance (nS)" }
    E_Na:  { value: 50.0 }
    E_K:   { value: -77.0 }
    I_amp: { value: 0.005,  description: "Pulse amplitude (nA)" }
    pulse_delay:    { value: 100.0, unit: ms }
    pulse_duration: { value: 100.0, unit: ms }
    gate_rate_scale: { value: 0.982, description: "Compensates flattened-representation phase drift" }
  derived_variables:
    I_ext:
      equation:
        rhs: "Piecewise((I_amp, (t >= pulse_delay) & (t < pulse_delay + pulse_duration)), (0.0, True))"
    alpha_m:
      equation:
        rhs: "Piecewise((1.0, Eq(v, -40.0)), (1.0*(v + 40.0)/(10.0*(1.0 - exp(-(v + 40.0)/10.0))), True))"
    beta_m:
      equation:
        rhs: "4.0*exp(-(v + 65.0)/18.0)"
    alpha_h:
      equation:
        rhs: "0.07*exp(-(v + 65.0)/20.0)"
    beta_h:
      equation:
        rhs: "1.0/(1.0 + exp(-(v + 35.0)/10.0))"
    rf_n:
      equation:
        rhs: "1.0/(3.2*exp(-1.125*v/25.3) + 0.3)"
      description: "KS forward rate for n gate (vHalfTransition)"
    rr_n:
      equation:
        rhs: "1.0/(3.2*exp(0.375*v/25.3) + 0.3)"
      description: "KS reverse rate for n gate"
  state_variables:
    v:
      equation:
        rhs: "(-g_Na*m**3*h*(v - E_Na) - g_K*n*(v - E_K) + I_ext*1000) / C"
      initial_value: -65.0
      variable_of_interest: true
    m:
      equation: { rhs: "gate_rate_scale*(alpha_m*(1 - m) - beta_m*m)" }
      initial_value: 0.052932
    h:
      equation: { rhs: "gate_rate_scale*(alpha_h*(1 - h) - beta_h*h)" }
      initial_value: 0.596121
    n:
      equation: { rhs: "gate_rate_scale*(rf_n*(1 - n) - rr_n*n)" }
      initial_value: 0.0
      description: "KS K+ channel open-state occupancy"
network:
  number_of_nodes: 1
integration:
  method: euler
  step_size: 0.01
  duration: 300.0
  time_scale: ms
""")
print(f"Model: {exp.dynamics.name}")
print(f"SVs: {list(exp.dynamics.state_variables.keys())}")
print(f"DVs: {list(exp.dynamics.derived_variables.keys())}")
Model: HH_KineticScheme
SVs: ['h', 'm', 'n', 'v']
DVs: ['I_ext', 'alpha_h', 'alpha_m', 'beta_h', 'beta_m', 'rf_n', 'rr_n']
Kinetic Scheme → ODE

The vHalfTransition between closed and open states is mathematically equivalent to an ODE \(dn/dt = r_f(1-n) - r_r n\). The KS open-state occupancy is the gating variable \(n\). No information is lost in the TVBO representation.
