# TVB-O Ontology

This folder is the home of the TVB-O (Virtual Brain Ontology) artifacts that
will be submitted upstream (W3C / community ontology hubs).

## Contents

| File | Origin | Purpose |
|------|--------|---------|
| `tvb-o-struct.owl` | generated by `make gen-owl` from `schema/tvbo_datamodel.yaml` | Structural OWL: classes, properties, ranges, domains. Source of truth for the runtime data model. |
| `tvb-o.shacl.ttl` | generated by `make gen-shacl` from `schema/tvbo_datamodel.yaml` | SHACL shapes for instance-level validation. |
| `tvb-o-axioms.ttl` | hand-authored | Additional OWL axioms (subclass hierarchies, equivalent classes, disjointness, etc.) that are *not* expressible in LinkML. Layered on top of `tvb-o-struct.owl`. |
| `tvb-o.owl` | merge of `tvb-o-struct.owl` + `tvb-o-axioms.ttl` | The complete TVB-O ontology, suitable for upstream PRs. |

## Generation

```bash
make gen-owl     # → ontology/tvb-o-struct.owl
make gen-shacl   # → ontology/tvb-o.shacl.ttl
```

`gen-owl` and `gen-shacl` outputs are checked into `ontology/` so external
consumers do not need a LinkML toolchain. CI rebuilds them on every PR and
fails if the committed copy drifts from the regenerated output.
